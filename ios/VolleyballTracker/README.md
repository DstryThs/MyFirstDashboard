# Volleyball Tracker (iOS)

A simple SwiftUI app to track volleyball matches on iPhone.

## Features
- Add matches with date, opponent, location, score, and notes.
- See a season summary (total matches, record, win rate).
- Delete matches with swipe-to-delete.
- Local persistence using `UserDefaults` (no account required).

## How to run
1. Open Xcode on macOS.
2. Create a new **iOS App** project named `VolleyballTracker`.
3. Replace the generated Swift files with the files in this folder.
4. Build and run on your iPhone simulator or device.

## Notes
- Data stays on your phone only.
- This starter is intentionally simple so you can expand it later (player stats, tournaments, etc.).
